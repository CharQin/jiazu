# 家族 Jiazu

一个以安卓手机为主要使用场景的亲属记录 App。使用 React、TypeScript 和 Capacitor，应用资源随 APK 内置，数据通过 IndexedDB 保存在本机。

## 功能

- 以自己家庭为中心的关系网，小家庭按分支聚合；父母、伴侣及兄弟姐妹连线。
- 亲属连接支持多位兄弟姐妹和儿女，保存时双向更新并自动同步家庭、辈分。根据已有伴侣和同胞资料自动补齐另一位父母及兄弟姐妹；不会创建未记录的父母，已有双亲不被覆盖。自动推导可随源关系改变而撤回，手动断开会保存。
- 家族图筛选仅保留「爸爸这边」「妈妈这边」两个 44px 大按钮，以橙色和紫色区分，点击已选按钮恢复全部亲人；名册保留原有分组筛选。
- 新增成员按父母与子女的分支位置插入；同一大家庭内的多个小分支分别对齐，夫妻中点尽量对准其子女组中点。夫妻跨家庭记录仍相邻；无关系资料的成员跟随所选家庭的附近层级，手动层新增同胞插入已知家人附近，保留原有手动顺序。
- 家族树按亲缘排序，父系祖先在左、母系在右，血亲分支相邻、配偶靠近。连线从卡片边缘出发，优先使用平滑曲线，自动绕开其他人物卡片，比较候选路径长度与交叉代价，避免为了少一次交叉产生很长绕路；家庭名称不参与避让，曲线可直接穿过；夫妻使用连续实线。
- 兄弟姐妹虚线默认使用加深的蓝灰色并轻微模糊，点击任一条即可点亮整组，再点一次收起。右上角「家族显示设置」提供 0–200% 饱和度滑杆，实时调整家族页面颜色并保存在本机。
- 默认显示按辈分分层的家族树：同辈水平对齐，各代使用独立底色与固定标签，同一亲属分支成员相邻，家庭框跟随分支位置，亲子从上往下连线；缺少某代时保留空层。
- 家族树长按人物 450 毫秒后左右拖动，可调整同辈顺序；夫妻成组移动，跨家庭时移动同辈家庭块，松手保存。支持 Alt 加左右方向键排序，显示设置可恢复自动排序。
- 删除成员后保持当前缩放，以视野附近的在场成员为参照补偿排版坐标变化，不再自动放大或跳回自己；最上层消失、连续删除及朋友分组同样处理。全图、回到我仍可主动重新定位。
- 拖动画布、双指缩放、全图、回到自己、全屏与分支筛选。父系、母系按与自己的父母连接自动识别，同住一家的父母分别归属两侧；未连接的成员保留手动家庭分支。
- 连接父母、伴侣后自动同步关联家人的辈分，自己固定为同辈；伴侣优先归入同一家庭，尚未独立成家的子女默认跟随父母，可手动调整家庭。冲突及超出五代范围的连接会提示。
- 起始空白个人卡显示「我」，不把它写入姓名。树图称呼独立显示，可换行完整显示 20 字称呼；年龄缩小放在姓名下。男性蓝色、女性粉色、未填性别中性色；伴侣相邻靠近，以爱心框标识，关系以平滑曲线连接。
- 紧凑的双列表单，性别默认无，家人/朋友直接选择，婚姻状况可选填；亲属连接置于家庭及辈分之前。
- 小家庭自动以在世家人中辈分最高、同辈年龄最大且有姓名者命名，离世成员与朋友不参与；有姓名且全家均已离世时显示「纪念家庭」；无姓名时家庭名称留白。编辑保存保持成员顺序，每次打开表单独立初始化。
- 家人名册与搜索；头像、生日、年龄、住址、电话、职业、标签和备注。所有资料可留空，自己的资料不显示称呼。
- 公历生日按年、月、日分别填写，可保存不完整日期；完整日期自动换算农历，包含闰月。
- 家庭名称旁的添加入口默认选择「家人」，并自动带入该家庭，可切换为朋友；「我的」页隐藏重复的右上角设置按钮。
- 每个家庭可添加朋友；默认折叠为家庭旁的一张成员卡片，展开名单后可查看资料、添加和记录往来。
- 实际关系路径、称谓计算器、农历生日卡片。
- 往来记录的新增、编辑、删除与搜索；自动列出最近 5 位在世家人的农历生日、对应公历日期和倒计时，包含今日生日。
- 新增家人默认选中「家人」；可选填「已离世」，家族树与关系网卡片变灰，年龄替换为小蜡烛与「已离世」，旧备份兼容。
- 家族图头像为 64px 圆角方形；自己与其他家人统一使用 160×116 卡片及相同选中样式，姓名区域加宽并支持两行显示，四字姓名不省略。称呼上移并放大为 14px，独立居中换行，保留完整 20 字。家庭名称在卡片下方独立显示，使用不透明底色，避开卡片和伴侣框，允许连线穿过家庭名称。伴侣卡片之间留出 32px，平滑曲线连接，其他家人间距更大。
- 农历计算使用随安装包内置的 lunar-typescript 1.8.7，无需联网；闰月生日当年无该闰月时按常月，三十遇小月按廿九，列表注明调整。
- 空白起步、本机持久保存、JSON 导出和恢复校验；升级时清除未改动的旧示例资料，保留用户填写的内容。
- 手机首页以家族树和关系网为主要内容，画布占据大部分可用空间。
- 添加家人始终新增亲属资料，包含「我对 TA 的称呼」；自己的资料从「我的 → 我的资料」完善。无资料、无关系的起始空卡在已有家人时自动隐藏，保留备份中的参照。
- 标准安卓输入连接，支持中文输入；表单随可见视口调整高度，并将当前输入项滚动至标题和保存栏之间。
- 安卓返回键、状态栏和导航栏安全区、原生文件分享备份。
- 婚姻状况仅提供已婚、未婚、其他，可留空或清空；旧备份中的离异、丧偶兼容读取，界面统一显示其他。
- 家人详情紧凑排列，顶部提供文字「编辑资料」按钮，底部右侧以红色突出删除，保留删除确认。
- 相册照片先进入头像裁剪，可拖动、双指缩放、使用缩放滑条及加减按钮，支持重置、取消和确认；安卓返回键先退出裁剪并保留表单草稿。
- 移除图表工具栏的添加朋友按钮和名册页顶部的添加家人按钮，保留底部「＋」及家庭内添加朋友入口。
- 图表控件仅保留全图和回到我；全图按所有家庭的边界缩放居中，避开左侧辈分标签和底部控件；手势缩放保留。

## 本地开发

需要 Node.js 24+。

```powershell
npm ci
npm run dev
```

```powershell
npm test
npm run lint
npm run build
```

## 构建安卓安装包

需要 Java 21、Android SDK Platform 36、Build Tools 和 Gradle 8.13。当前电脑已提供相关工具，SDK 位于 `D:\Android\sdk`。

```powershell
npm run android:build
```

指定其他 SDK 路径：

```powershell
pwsh -NoProfile -File scripts/build-android.ps1 -SdkPath 'C:\Android\sdk'
```

脚本会构建前端、同步到 Android 工程并生成签名 release APK，输出到 `releases/家族-v1.8.0.apk`。依赖已缓存时可使用 `npm run android:build -- -Offline`。也可以在 Android Studio 中打开 `android` 目录。

首次构建会在本地创建 `android/keystore/jiazu-release.jks` 和 `android/keystore.properties`。这两项均已加入忽略规则。**请私下备份并保留它们**：后续覆盖安装必须继续使用同一密钥。不要把签名配置或密钥上传到公开仓库。

应用包名：`cn.jiazu.family`；最低 SDK：24；目标 SDK：36。

## 目录

- `src/model.ts`：数据模型、IndexedDB、备份校验和关系路径。
- `src/FamilyMap.tsx`：关系网、辈分标签和画布手势。
- `src/kinship.ts`：父母角色、关系辈分同步、人员分支识别与家庭推导。
- `src/treeLayout.ts`：同辈对齐、家庭相邻、空代保留的树状布局。
- `src/kinshipOrdering.ts`：从自己的父母关系推导父系、母系和旁系的排列顺序。
- `src/mapRouting.ts`：避开卡片的曲线、实线及兄弟姐妹连线。
- `src/familyRelations.ts`：显式兄弟姐妹、共有父母及整组连线识别。
- `src/forms.tsx`：成员编辑、往来、称谓计算和空白家族。
- `src/components.tsx`：资料面板和通用组件。
- `src/MainApp.tsx`：页面导航和应用操作。
- `android`：安卓工程。
- `tests`：真实关系路径、循环关系、备份、日期及辈分布局测试。
- `使用说明.md`：给使用者的操作说明与现有边界。

本版本使用普通话称谓库 relationship.js（MIT），以及 lunar-typescript（MIT）、React（MIT）、lucide-react（ISC）和 Capacitor（MIT）。

## 数据和验证

没有服务器或云账号。照片在设备内压缩成 240×240 JPEG，保存在本地资料及导出备份中。清除应用数据或卸载会移除本机资料；导出的备份为明文 JSON。

自动测试包含 94 项关系、兄弟姐妹与儿女同步、在世家人自动命名、备份、选填生日、农历、旧示例迁移、辈分/朋友布局、共同父母的稳定排版、避卡片绕线、全图视口及头像裁剪几何校验。手机宽度 390 和 320 的浏览器检查记录见 `qa/verification.json`。当前未连接安卓设备，系统相册、分享、实际双指和长按拖动手势仍需真机验收；浏览器已验证键盘排序、重载恢复和自动补线表单。
